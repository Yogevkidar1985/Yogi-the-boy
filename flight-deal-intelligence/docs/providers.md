# מנועי חיפוש — טבלת מקורות והוראות הטמעה

מסמך זה מרכז את כל מקורות הטיסות שהמערכת יודעת לעבוד מולם, מה נדרש כדי להפעיל כל אחד,
והיכן מזינים את המפתח. כל המקורות הפעילים נסרקים **במקביל** בכל חיפוש; כשל של מקור אחד
לעולם לא מפיל את החיפוש.

יש שתי דרכים להזין מפתחות:

| דרך | מתי להשתמש | יתרון |
|---|---|---|
| **Render → Environment** | מקורות מובנים (SerpAPI, Duffel, Travelpayouts…) | סטנדרטי, מפתחות לא נשמרים בבסיס הנתונים |
| **מסך הניהול** `/admin.html` | כל API אחר, בכמות גדולה | הוספה מיידית ללא פריסה מחדש, ניהול מגבלות קצב לכל מנוע |

## 1. מקורות מובנים

| מקור | סוג תוכן | מצב גישה (אוגוסט 2026) | משתני סביבה | עלות |
|---|---|---|---|---|
| **SerpAPI** | Google Flights | הרשמה עצמית — פתוח | `SERPAPI_API_KEY` | מכסה חינמית ואז לפי שימוש |
| **Travelpayouts / Aviasales** | מחירים זולים (מטמון) | הרשמה עצמית — פתוח | `TRAVELPAYOUTS_TOKEN`, `TRAVELPAYOUTS_MARKER` | חינם |

| **Amadeus** | GDS | **Self-Service נסגר 17.7.2026** | `AMADEUS_CLIENT_ID`, `AMADEUS_CLIENT_SECRET` | Enterprise בלבד (דורש IATA/ARC) |
| **Kiwi Tequila** | Virtual interlining / LCC | בהזמנה בלבד מאז 2024 | `KIWI_API_KEY` | לפי הסכם שותפות |
| **fast-flights** | Google Flights (ללא מפתח) | ללא מפתח | — | חינם, אך Google חוסם שרתי ענן |

> **סדר עדיפות מומלץ להטמעה:** Travelpayouts (חינם, מיידי) ← SerpAPI (תוצאות Google אמיתיות) ← Duffel (NDC).

### הוספת מפתח ב-Render

1. Dashboard ← השירות `flight-deal-intelligence`
2. לשונית **Environment** ← **Add Environment Variable**
3. שם המשתנה + הערך מהטבלה
4. **Save** — Render יפרוס מחדש אוטומטית
5. `/providers.html` ← **בדיקת חיבור** כדי לוודא שהמקור באמת עונה

## 2. הוספת מנועים דרך מסך הניהול (20–30 מנועים)

### הפעלה חד־פעמית

הוסיפו ב-Render שני משתנים:

| משתנה | תפקיד |
|---|---|
| `ADMIN_TOKEN` | סיסמת הכניסה למסך הניהול |
| `ADMIN_SECRET` | מחרוזת ארוכה (20+ תווים) להצפנת מפתחות ה-API בבסיס הנתונים |

בלי `ADMIN_SECRET` המערכת **מסרבת** לשמור מפתחות — כדי שלא יישמרו בטקסט גלוי.

### שדות ההגדרה של מנוע

| שדה | הסבר | דוגמה |
|---|---|---|
| שם מזהה | אנגלית, ייחודי | `flightapi` |
| כתובת API | עם תבניות | `https://api.x.com/s?key={KEY}&from={origin}&to={destination}&date={departureDate}` |
| מפתח API | נשמר מוצפן AES-256-GCM | `abc123…` |
| כותרות | JSON, תומך `{KEY}` | `{"Authorization":"Bearer {KEY}"}` |
| נתיב לתוצאות | נתיב JSON למערך | `data.itineraries` |
| מיפוי שדות | JSON — שדה → נתיב בתשובה | ראו למטה |
| בקשות לדקה / מקביליות / timeout | מגבלות קצב לכל מנוע בנפרד | `30` / `4` / `20000` |

### תבניות זמינות בכתובת ובכותרות

```
{KEY} {origin} {destination} {departureDate} {returnDate}
{adults} {children} {infants} {cabin} {cabinTitle} {cabinLower} {currency}
```

### מיפוי שדות

```json
{
  "price": "fare.total",
  "currency": "fare.currency",
  "airline": "carrier.iata",
  "airlineName": "carrier.name",
  "flightNumber": "carrier.number",
  "departureTime": "dep",
  "arrivalTime": "arr",
  "stops": "stopCount",
  "durationMinutes": "durationMin",
  "bags": "baggage.checked",
  "bookingUrl": "link"
}
```

חובה: `price` בלבד. שדה שה-API לא מחזיר נשאר ריק — המערכת **לא ממציאה ערכים**,
ותוצאה בלי מחיר נזרקת.

### לאחר ההוספה

המנוע מצטרף לחיפוש המקבילי **מיד**, בלי פריסה מחדש. בטבלה יש לכל מנוע כפתורי
**בדיקה** (חיפוש אמיתי מולו), **השהיה** ו**מחיקה**.

## 3. מה קורה מאחורי הקלעים לכל מנוע

| מנגנון | התנהגות |
|---|---|
| מקביליות | כל המנועים הפעילים נשלחים בו-זמנית |
| Timeout | לכל מנוע timeout משלו; מנוע תקוע לא מעכב את השאר |
| Rate limiting | token bucket לכל מנוע: בקשות לדקה + מקביליות מקסימלית |
| Circuit breaker | 3 כשלים רצופים → השהיה של 5 דקות → ניסיון בדיקה יחיד |
| Cache | תוצאות זהות נשמרות; חיפושים זהים מקבילים מתאחדים לקריאה אחת |
| דדופליקציה | אותה טיסה מכמה מנועים מתמזגת לכרטיס אחד, עם השוואת מחירים בין המקורות |
| אימות כיוון | תוצאה שלא טסה בכיוון המבוקש נזרקת ונרשמת ללוג |
| תקציב תשלום | מכסה יומית לקריאות למקורות בתשלום (`PAID_REQUESTS_PER_DAY`) |

---

## 4. אבטחה

- מפתחות **לעולם לא נשלחים לדפדפן** — ה-API מחזיר רק אם מפתח קיים או לא.
- מפתחות שנשמרים בבסיס הנתונים מוצפנים ב-AES-256-GCM.
- כל נתיבי הניהול דורשים `X-Admin-Token`; ללא `ADMIN_TOKEN` מוגדר הם מחזירים 503.
- קישורי הזמנה מספקים עוברים אימות סכימה (http/https בלבד) לפני הצגה.
