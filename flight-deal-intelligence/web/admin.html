כניסת מנהל

השרת עדיין לא הוגדר, ולכן שדה הסיסמה מושבת

המשתנה ADMIN_TOKEN אינו מוגדר בשרת. כל עוד הוא ריק אין סיסמה להשוות אליה, ולכן אין מה להקליד כאן. כך מגדירים:

  1. dashboard.render.com ← השירות שלכם ← Environment
  2. Add Environment Variable: ADMIN_TOKEN = סיסמה שתבחרו
  3. עוד משתנה: ADMIN_SECRET = מחרוזת אקראית של 20+ תווים (מצפינה את מפתחות ה-API)
  4. Save Changes — Render מפרס מחדש; ממתינים 1–3 דקות
  5. חוזרים לכאן ולוחצים בדיקה מחדש
איך זה עובד

כל מנוע שמוסיפים כאן נשמר בבסיס הנתונים, מצטרף מיד לחיפוש המקבילי (בלי פריסה מחדש), ומקבל מגבלות קצב משלו. מפתחות ה-API נשמרים מוצפנים (AES-256-GCM) ואינם מוחזרים לדפדפן — רק סימון שקיים מפתח.

הוספת מנוע חדש

שולח בקשה אמיתית אחת ל-API, קורא את התשובה וממלא את נתיב התוצאות ומיפוי השדות לפי מה שהוחזר בפועל. אין ניחושים: שדה שלא זוהה נשאר ריק.
תבניות זמינות ודוגמה מלאה
בכתובת ובכותרות אפשר להשתמש ב:
{KEY} {origin} {destination} {departureDate} {returnDate} {adults} {children} {infants} {cabin} {cabinTitle} {cabinLower} {currency}
דוגמה למיפוי — כל ערך הוא נתיב בתוך אובייקט התוצאה:
{"price":"fare.total","currency":"fare.currency","airline":"carrier.iata","stops":"stopCount","departureTime":"dep","arrivalTime":"arr","durationMinutes":"durationMin","bookingUrl":"link"}
שדה שה-API לא מחזיר פשוט יישאר ריק — המערכת לא ממציאה ערכים. תוצאה בלי מחיר נזרקת.
